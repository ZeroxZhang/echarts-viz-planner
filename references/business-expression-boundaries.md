# 业务表达的前提与边界

仅在候选涉及下列业务表达时读取对应行；通用选型仍走 [selection.md](selection.md) 和完整目录。本文件补充语义与数据前提，不增加 `capability_id`、组件承诺、数量配额或固定版式。目录未单列的表达通过已有且满足数据/运行契约的 `custom.custom`、信息图或表格说明规格；不能把本文名称直接写成新 ID。上游负责实现、看图与交付检查。

## 数值比较、构成与尺度

| 表达 | 成立前提与应说明的信息 | 换型或降级边界 |
|---|---|---|
| Mekko | 类别总量非负且构成同一整体；每类组成可加且口径一致。列宽∝类别总量、段高∝该列份额，面积才∝绝对量；零总量没有可定义的组成比例，保留原值另列 | 任务是精确比较中间段时改共用基线比较或表格；只关心份额用百分比堆积。无真实总量不用手摆列宽 |
| 指数化趋势 | 对每条序列用 `value / base_value × 100`，明确基期、基值与原单位。基期为零不能相除；负基值使相对变化难解释，优先原值分面。各序列基期需可比 | 指数只比较相对轨迹，不证明绝对规模；不要混入未归一化的原值曲线 |
| 龙卷风敏感性 | 明确同一输出指标、基准情景、每个输入的低/高假设及对应输出；排序依据声明为输出范围或相对基准影响，不混用 | 单因素变化不等于多因素联合概率；无模型依据不画估算敏感性。两群体镜像条形是另一语义，分别说明群体、单位与共享尺度 |
| 小倍数 | 任务需要跨面板比较大小时共享单位、数值域、刻度与类别/时间口径；缺失观测保留缺失。同轴配置不是自动布局已通过 | 各自尺度仅适合看各自形状，须明确标注且不能再作跨面板大小比较；拥挤可按业务分组、拆页，不能靠缩字或静默换轴 |
| 柱线/双轴 | 两侧单位、系列归属与刻度直接可见；收入与增长率可用不同标记分工，但不得按两轴同一高度比较大小 | 轴范围能制造虚假同步；需要比较相对轨迹优先指数化，需要各自绝对量优先分面；图形同时变化不证明因果 |

## 预测与经济解释

| 表达 | 成立前提与应说明的信息 | 换型或降级边界 |
|---|---|---|
| 曲棍球/预测线 | 历史观测与预测用直接文字及线型区分；拐点注明驱动条件、模型或假设，目标不能冒充预测 | 无预测依据时只画已知历史，并把目标/情景独立说明；不能因叙事需要补造拐点 |
| S 曲线 | 除增长阶段外还隐含趋于饱和的机制或假设；标明阶段判断和饱和水平依据，区分拟合、外推与概念示意 | 几个上升观测不足以确定饱和上限；只表达概念阶段时不用数值轴制造预测精度 |
| 成本曲线 | 横轴为累计产能/产量，纵轴为同口径单位成本；明确排序及成本范围。每个生产单元占据其真实产能宽度，价格线与成本单位一致 | 普通等宽柱不编码累计产能；成本与价格比较须说明是否含固定成本等范围，不能自动推出完整会计利润或退出决策 |
| 经验曲线 | 横轴为累计产量，明确单位成本口径。若采用 `C(Q)=aQ^b`，每翻倍成本保留率为 `2^b`，例如 85% 表示保留 85%、下降 15%；数据或假设支持参数才报告参数 | 幂关系在双对数轴可成直线，仅把 x 轴设为 log 不等价；零/负值不能直接上对数轴。时间趋势或规模相关本身不证明学习因果 |
| 利润池 | 用同期间同范围的环节利润额回答利润在哪里，利润率另说明分母；环节需避免重复计算，亏损不能省略 | 收入不是利润。若同时画利润额/利润率，遵守双轴边界；口径无法闭合时列分项与限制，不强算全行业总池 |
| 驱动/利润树 | 定量树每层写明公式、单位、数值与口径，核对父子关系；分支可有加法、乘法等不同运算，不能一律求和 | 会计分解不等于经营原因；不可行动叶子应指向进一步分析。无数量公式时用议题/机制树并说明假设，不冒充定量归因 |

## 定性判断与责任、计划

| 表达 | 成立前提与应说明的信息 | 换型或降级边界 |
|---|---|---|
| 能力/成熟度、Harvey ball | 先定义档级与证据，当前/目标使用同一量尺；空白/未知与最低档分开。若使用 0、¼、½、¾、满圆，这是五个符号等级，不自动代表精确比例 | 无评分依据仍可展示能力结构，不能虚构等级填色；连续实测量宜用数值表/热力。符号语义附文字图例 |
| RAG 状态 | 明确正常/风险/偏离的判断标准，配文字或形状；需要干预的状态关联行动与责任 | 不以颜色作为唯一通道；红色不是行动结论，绿色也不证明无风险 |
| 业务评分卡 | 只呈现有来源的业务评分、锚点、权重和透明计算；明确各标准是否允许加权相加，保留重要否决条件与不确定性 | 此处不允许 planner 为候选图型、置信度或匹配度生成数字得分；选型判断继续使用定性等级。业务评分缺依据时用条件化比较表 |
| RACI | 行为活动、列为角色，解释 R/A/C/I；通常每项明确单一最终问责者，若实际治理另有约定须说明。A 与 R 可由同一角色承担，不视为自动错误 | 责任未知则标待定，不为填满表格编造角色。汇报关系用组织图，不能由 RACI 推断上下级 |
| 2×2/九宫格 | 定量轴给出真实尺度与分界依据；定性轴说明档位、判据和证据，位置不暗示未经测量的距离 | 不为让主体分散而移动真实数据；两轴无行动含义时用比较表，象限名称不能代替结论论证 |
| 甘特/路线图/里程碑 | 有真实起止日期才用位置/长度编码持续时间；注明依赖、阶段和责任中已知的部分。里程碑是结果/交付事件，不能冒充一段持续任务 | 日期未定可用等距阶段与前置条件，明确非时长比例；缺依赖不补确定箭头，任务过细按受众需要分组 |
| 概念结构与集合 | 价值链环节、战略屋层级、鱼骨候选原因、概念漏斗筛选、维恩交集应各有明确含义；层级或交集面积未计量时说明为示意 | 不以图形形状证明因果、成熟度或规模；鱼骨候选原因须验证，概念筛选与同批对象真实转化分开 |

以上是具体表达的必要说明及误用边界；不要求每个任务产生一张附加表。只把影响当次结论的前提落实到规格、来源与可见说明中。
