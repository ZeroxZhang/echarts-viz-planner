# 数据清洗与溯源细则

> SKILL.md §10 是硬规则，本文档是执行细则。目标：任何清洗动作都能回答「原值是什么、做了什么、为什么、影响了什么、能不能反悔」。

## 1. 清洗三档（对照 SKILL.md §10）

### 第一档：自动执行（不需要记录到人，但保留在版本中）
- 删空白行列；字段名去首尾空格
- 识别并剔除嵌套表头、合计行（标记 `totals_removed: N`）
- 标准化日期 / 数字 / 百分比 / 货币格式（`12.5%` → `0.125` 须记录换算）
- 统一空值表达（""、"-"、"N/A"、"null" → null）
- 标记重复行（不删除）
- 拆解组合字段（"北京-海淀" → 城市/区县，保留原字段）
- 时间排序

### 第二档：执行但必须记录（进溯源台账，interactive 呈现、api 写成 transforms）
- 类目别名归一（"北京" vs "北京市" → 统一，映射表保留）
- 单位换算（万元→元）
- 粒度转换（日→月聚合：注明 sum/mean 口径）
- 宽转长 / 长转宽
- 多表关联（注明 join 键与方向；join 关系不明 → 第三档）
- 聚合抽样（注明抽样方式 + 种子 + 比例）
- 派生指标（同比/环比/占比/贡献度：公式必须可复算）
- 从累计值算增量

### 第三档：必须询问或保留原值（interactive 提问/标注；api 取保守默认并进 open_questions）
- 删异常值（含未来日期、负值销量等——真实测试案例：movies 的 Release Date 出现 2046 年）
- 填补缺失
- 合并疑似同一实体
- 冲突口径二选一
- 把 `0` 解释为缺失
- 改变统计粒度
- 会显著改变结论的数据裁剪

## 2. 冲突检测清单（命中即标记，不得自行选择）

1. 同名指标口径不同（如两份材料的「GMV」定义不同）
2. 同区间数据不一致（同一月两个数字）
3. 多份文件都自称「最新」
4. 类目合并会改变结果
5. Join 关系不明
6. `0` 的语义不明（真零 vs 缺记录）

处置：interactive → 按影响程度决定是否计入唯一的澄清问题；api → 进 `open_questions`（blocking: false）+ `assumptions`（默认取保守值）。

## 3. 溯源台账格式（内部保留；interactive 只呈现摘要，api 只回 transforms）

```
| # | 原值 | 动作 | 原因 | 影响行数 | 可逆 | 经确认 |
| 1 | "北京市" | 归一为 "北京" | 别名合并 | 12 | 是 | 否 |
| 2 | 日级销售 | 聚合为月 sum | 看月度趋势 | 365→12 | 是 | 否 |
| 3 | 2046 年份 | 保留原值待确认 | 疑似脏数据 | 0 | — | 待确认 |
```

api 模式的算子语法见 `references/api-contract.md` §2.2（filter/aggregate/derive/sample/normalize…），不得用自然语言代替算子。

## 4. 访问异常强制动作（材料盘点时执行）

| 状态 | interactive | api |
|---|---|---|
| 无权限 | 告知无法访问，请求导出或授权；**不根据标题猜测内容** | `status: insufficient_data` + `missing` |
| 超时/失效 | 重试一次，仍失败标 `unavailable`，列出受影响分析点 | 同上 + 受影响分析点 |
| 超阈值（>5 万行 / 类目>200） | 先聚合或抽样，显式标注方式；提示 dataZoom + thumbnail | `transforms` 写抽样算子，`risks` 标注 |
| 截图/OCR | 标来源与置信度，关键数字请对方复核 | `assumptions` 标 OCR 来源，`impact: high` |

## 5. 画像消费提示（配合 scripts/profile_data.py 输出）

- `missing_rate > 50%` 的字段：默认弃用，除非业务上该字段就是稀疏的（如可选属性）。
- `cardinality > 200` 的类目字段：聚合或抽样；做图时并入「其他」。
- 数值字段被画像判为维度（基数 ≤ 12）：先确认是不是编码值（如年份、等级），不是则改判指标。
- `possible_time_fields` 中的字段若语义是「车型年」「版本期」而非观测时间，**不作时间轴**（真实测试案例：cars.Year）。
- 画像的维度/指标建议是启发式，不替代业务口径判断。
