# 视觉质量规范

> 什么时候读本文档：给完整 option、把视觉规范固化进产物时。图选对了但做得难看等于没做。
> api 模式：以下规范必须**固化进返回的 option**（写成配置，不是写成建议文字），上游才不会拿到丑图。

## 1. 配色

- 连续量：单色相渐变（如浅蓝→深蓝），禁止彩虹色映射连续值。
- 分类色板：上限 8 色；超出并入「其他」（灰色）。
- 强调色：只用一个；主序列用强调色，其余弱化。
- 色盲友好优先（蓝/橙），避免红绿对比作为唯一区分。
- 语义色：正向/负向/中性分别用约定色，且不与非语义序列混用。
- 深色主题：降低饱和度、提高文字对比度，同一组语义色在 dark/light 下保持映射一致。

## 2. 文字与标签

- 坐标轴标签超 6 字 → 改横向条形图，或旋转 ≤ 30°。
- 数值标签：类目 ≤ 12 时全量显示；否则只标首尾与极值。
- 轴标题只在单位不明确时出现；单位放轴名或 tooltip，不重复堆字。
- 图例顺序与视觉顺序一致（如排名降序）。
- 数字格式统一：千分位、小数位与数据口径一致；百分比统一一位小数或整数。

## 3. 网格与轴线

- 去掉竖向网格线；保留横向参考线（≤ 5 条）或直接关网格。
- 去掉图表边框（splitLine 顶/右侧）。
- Y 轴从 0 起；折线可例外，但截断必须显式标注（axisLabel 起始值 + 视觉提示）。
- 双 Y 轴：不同量纲必须标注两侧轴名；能用归一化单轴就不用双轴。

## 4. 载体适配

| 载体 | 默认规格 |
|---|---|
| 飞书文档内 | 宽 100%、高 360–420px；文字 ≥ 12px |
| 独立网页 | responsive；断点 < 768px 时隐藏图例、改用 tooltip |
| 移动端 | 单图单屏；tooltip 触发 `item` 而非 `axis` |
| 汇报投屏 | 高对比、大字号（≥ 14px）、弱化网格 |

## 5. 禁用清单（出现即错）

- 3D 饼图（扭曲面积感知）
- 双 Y 轴不同量纲且不标注
- 面积图叠加超 4 层（中部层形态失真）
- 无意义动画（非动态排序场景的入场动画）
- 玫瑰图表达非周期数据
- 彩虹色映射连续值
- 装饰性 3D（默认禁用 echarts-gl 的原因）

## 6. 大数据量配置（> 5 万行或类目 > 200）

- 必须配 `dataZoom`（inside + slider）+ `thumbnail`（ECharts 6 新增）。
- 开启 `sampling: "lttb"`（折线降采样），`large: true`（散点）。
- 关闭全部数值标签；tooltip 只回显聚合层数据。
- 视觉规范优先级：性能 > 交互 > 装饰。

## 7. 无障碍底线

- `aria: { enabled: true }`（api 输出默认开启）。
- 文字对比度 ≥ 4.5:1（正文）。
- 不把颜色作为唯一信息通道：关键差异叠加形状/纹理/标签。

## 8. option 固化示例（api 模式输出应达到的形态）

```json
{
  "series": [{ "type": "bar", "barMaxWidth": 40, "itemStyle": { "color": "#2f6fed" } }],
  "xAxis": { "type": "category", "axisLabel": { "rotate": 0, "width": 60, "overflow": "truncate" } },
  "yAxis": { "type": "value", "scale": false },
  "grid": { "top": 40, "left": 8, "right": 8, "bottom": 8, "containLabel": true },
  "tooltip": { "trigger": "axis" },
  "aria": { "enabled": true }
}
```

主题遵循上游 `theme`，缺省 `light`；颜色取自对应主题色板而非写死色值（写死仅当上游要求品牌色）。
