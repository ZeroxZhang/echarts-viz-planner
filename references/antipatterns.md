# 反模式清单

> 出现下列任一模式即为错误输出。来源：v3 方案视觉禁用清单 + 真实数据测试中暴露的误判。
> 分为三类：视觉反模式（§1）、选型反模式（§2）、流程反模式（§3）。

## 1. 视觉反模式（渲染级错误）

| # | 反模式 | 为什么错 | 正确做法 |
|---|---|---|---|
| V1 | 3D 饼图 | 透视扭曲角度/面积感知 | 平面 donut 或 bar.rank |
| V2 | 双 Y 轴不同量纲且不标注 | 读者无法区分曲线归属 | 标注两侧轴名；或归一化单轴 |
| V3 | 面积图叠加超 4 层 | 中部层形态完全失真 | top-N + 其他；或 themeriver（也要控层数） |
| V4 | 无意义动画（入场/旋转） | 纯装饰拖慢阅读 | 仅动态排序（bar.dynamic）保留动画 |
| V5 | 玫瑰图表达非周期数据 | 面积按半径平方放大，误导 | pie.donut / bar.pct |
| V6 | 彩虹色映射连续值 | 色调无顺序语义 | 单色相渐变（visualMap） |
| V7 | 分类色板超 8 色 | 不可区分 | 并入「其他」 |
| V8 | 类目 ≤12 却不标数值、类目 >12 却全量标注 | 该读的不标，标了的读不了 | ≤12 全量，>12 只标首尾与极值 |
| V9 | 竖向网格线 + 图表边框 | 视觉噪音 | 去竖线，至多 5 条横参考线 |
| V10 | Y 轴不从 0 起且不标注截断 | 夸大差异 | 从 0 起；折线例外须显式标注 |
| V11 | 标签超 6 字仍纵向排列 | 斜排/截断难读 | 改横向条形（bar.rank） |
| V12 | 颜色是唯一信息通道 | 色盲/打印失效 | 叠加形状/纹理/标签 |

## 2. 选型反模式（决策级错误）

| # | 反模式 | 为什么错 | 正确做法 |
|---|---|---|---|
| S1 | 类目 >6 还用饼图 | 角度感知失效（真实测试：12 类型→饼图全灭） | bar.rank / bar.pct |
| S2 | 数值不构成整体还画构成图 | 占比无业务含义 | 先验证守恒语义；否则 bar.grouped |
| S3 | 流向有环还选桑基图 | sankey 禁止环路 | graph.force |
| S4 | 关系双向对称却用桑基 | 单向守恒语义不成立 | chord.chord |
| S5 | 无数值字段选 treemap/sunburst | 面积编码无米下锅 | tree.tree |
| S6 | 样本 <30 画直方图 | 分箱失真 | beeswarm / 列表 |
| S7 | 样本 >300 画蜂群图 | 点重叠 | boxplot / violin |
| S8 | 连续变量硬套矩阵热力 | 需要双类目交叉 | scatter.basic / ext.contour |
| S9 | 时间点 ≤2 画折线 | 线没意义 | bar.basic / text.conclusion |
| S10 | 4 个数的图（单值对比硬画图） | 图表无模式可表达（真实测试 T5） | 表格 / 一句话结论 |
| S11 | 地区只是分组标签却上地图 | 面积编码误导 | bar.rank |
| S12 | 地图名对不上 GeoJSON 硬套 | 渲染缺块或错配 | 硬淘汰，转排名条形 |
| S13 | 无事件语义用涟漪散点 | 动画强调没有目标 | scatter.basic |
| S14 | 默认启用 3D | 遮挡降低读数精度 | 默认禁用，显式要求才启用 |
| S15 | 用被禁的 echarts-wordcloud/liquidfill | peer 仅 ^5.0.1，不兼容 6.x | @echarts-x 对应包 |
| S16 | 直接推荐扩展却不声明依赖 | 上游无法复现 | echarts.deps 声明 package@version |

## 3. 流程反模式（契约级错误）

| # | 反模式 | 为什么错 | 正确做法 |
|---|---|---|---|
| P1 | 输出数字得分/加权总分 | 不可复现、不可审计、本质编造 | 定性等级（match/confidence）+ 依据 |
| P2 | 淘汰候选不留理由 | 决策不可审计 | 一句话理由；api 进 rejected |
| P3 | 材料里的既有结论直接当结论输出 | 未经验证的观点 | 标注「待验证观点」，独立核实 |
| P4 | 无权限/打不开的链接按标题猜内容 | 编造数据事实 | insufficient_data / 请求导出 |
| P5 | api 模式提问 | 上游无人应答，流程卡死 | assumptions + open_questions（blocking:false） |
| P6 | api 回传数据本体 | 契约违约 + 体积爆炸 | 只回 ref + profile + binding |
| P7 | 运行时查 npm latest | 联网依赖 + 预发布风险 | 锁定 6.1.0，check_version.py 离线核验 |
| P8 | 清洗不可追溯（直接改数不记录） | 图、表、正文口径漂移 | 溯源台账 / transforms 算子 |
| P9 | 用户指定了错图，擅自替换 | 违背调用方意图 | 先执行 + 指出风险与更优解（api 写 risks+alternatives） |
| P10 | 未核实数字冒充事实 | 红线 | 缺来源写 `【待补充：xxx】` |

## 4. 自检口令（输出前 10 秒过一遍）

构图构成验证守恒？类目数在图种上限内？样本量在契约区间内？扩展依赖已声明？有没有数字得分？
每一个 rejected 都有一句话理由？api 有没有提问/回传数据？Y 轴截断标注了吗？
